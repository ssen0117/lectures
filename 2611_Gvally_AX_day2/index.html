① RSS 모듈 — 글 가져오기

  1. 캔버스 가운데 + → 검색창에 RSS
  2. Retrieve RSS feed items 선택
  3. URL 칸에 STEP 1에서 받은 주소 붙여넣기
  4. 가져올 글 개수는 10 정도면 충분 → OK
  5. 모듈 우클릭 → Run this module only → 글이 들어오는지 확인

Watch는 "새 글이 생길 때마다", Retrieve는 "돌릴 때마다 지금 있는 글을 가져오기"예요. 하루 한 번 묶어 받는 오늘 방식엔 Retrieve가 맞아요.

② Gmail 모듈 — 메일 보내기

  1. RSS 모듈 오른쪽 반원 클릭 → Gmail 검색 → Send an email
  2. Connection → Add → 내 Google 계정으로 로그인 → 허용
  3. To: 내 Gmail 주소
  4. Subject: 메일 제목 (예: 오늘의 리뷰 모음)
  5. Content: 칸 클릭 → 매핑 패널에서 Title, URL 블럭을 클릭해서 꽂기

③ 메일 본문은 코드로 써도 돼요

Content 칸은 글자뿐 아니라 HTML 코드도 받아요. 블럭을 하나하나 꽂는 대신, Claude에게 메일 모양을 코드로 받아 붙여넣고 자리만 블럭으로 바꾸면 끝이에요.

PROMPT · 메일 모양을 코드로 Gmail 메일 본문을 제목, 링크, 날짜가 보기 좋게 나오는 HTML 코드로 만들어줘. Make 매핑 블럭 들어갈 자리는 [TITLE 자리], [LINK 자리] 이런 식으로 표시해줘.

Claude가 준 코드를 Content 칸에 복붙 → [TITLE 자리] 같은 부분만 지우고 그 자리에 매핑 블럭을 꽂으면 돼요. 다음 STEP에서 Text aggregator를 넣으면 이 코드는 aggregator 쪽으로 옮겨가요. Claude가 같이 안내해줘요.

Text aggregator 사용법

하는 일 — 여러 개를 하나로 합쳐주는 모듈. RSS가 글 10개를 뱉으면 → 한 덩어리로 묶어 메일 1통에 담아요.

위치 — RSS → [Text aggregator] → Gmail

설정 3가지

  1. Source Module → RSS 선택 (필수! 안 하면 안 돌아감)
  2. Row separator → New row
  3. Text → 아래 템플릿 복붙 후, [...] 자리는 오른쪽 매핑 패널에서 RSS 필드 클릭해서 채우기
Text 템플릿 ━━━━━━━━━━ 📌 [Title] 🔗 [URL] [Description]

Gmail 연결 — Gmail 모듈 Content 칸에 Text aggregator 출력을 한 번 클릭해서 넣으면 끝.

안 되면 Claude에게 — "Text aggregator Source Module 어떻게 설정해?" / "결과가 비었어, 원인이 뭐야?" (스크린샷 같이 올리면 더 빠름)

STEP 1-b · 복사해서 자기 걸로 바꾸기 이 메모의 내용을 우리 회사 버전으로 바꿔줘. 우리 회사는 [업종·하는 일]하는 회사야.

예: "산업용 정수 필터를 학교 급식실·식품공장·병원에 납품하는 회사"
수업용 데이터를 본인 회사 맥락으로 바꿔서 이후 단계를 진행합니다.

1-c 쉽게 일할 수 있게

STEP 1-c · 복사 이 메모 가지고 더 쉽게 일할 수 있도록 시각적으로 잘 정리해줘.

"어떻게" 정리할지는 말하지 않습니다. Claude가 데이터 성격에 맞는 방식을 알아서 제안해줘요.

뭘 어떻게

STEP 2 · 복사 이 데이터 가지고 영업 현황을 한눈에 볼 수 있는 보드 아티팩트를 만들려고 해. 어떤 걸 어떻게 보여주면 좋을지 알려줘.

"어떤 걸" = 어떤 숫자나 정보. "어떻게" = 어디에 어떤 모양으로. Claude가 보드 구성을 글로 설계해줍니다. 아직 눈에 보이진 않아요.

파일명을 index.html로

배포 서비스는 도메인 루트에 접속하면 index.html을 찾습니다. 이름이 다르면 404 페이지가 떠요.

  1. Claude Artifact에서 다운로드한 HTML 파일을 찾아요
  2. 파일명을 index.html로 변경
  3. 이 파일을 서비스에 올리면 됩니다

여러 파일(이미지·css 등)이 같이 있다면 그 폴더 전체를 올리되, 첫 화면 역할 HTML이 index.html이어야 해요.

OPTION A Cloudflare로 올리기

Cloudflare에
올리기

Google 로그인 1분 + 파일 하나 올리면 공유 가능한 URL이 바로 나와요.

가입 (1분)

  1. dash.cloudflare.com/sign-up 접속
  2. 이메일 + 비밀번호로 가입 → 받은 메일에서 확인 링크 클릭

배포 — 4단계

  1. 좌측 메뉴 Compute → Workers & Pages → Create
  2. Upload your static files 선택
  3. index.html 파일을 창에 드래그드롭 → 프로젝트 이름 확인 후 배포
  4. 우측 상단 Visit ↗ 버튼으로 내 페이지가 뜨는지 확인
    URL 예: floral-butterfly-a6f3.내이름.workers.dev
수정본은 어떻게? 만든 Worker 화면 → 우측 상단 New deployment → 새 index.html 드래그드롭. URL은 그대로, 내용만 바뀝니다.
좀 더 깎아보기

404 "페이지를 찾을 수 없음"이 뜰 때

십중팔구 파일명이 index.html이 아니에요. 공통 준비 쪽 확인 후 재업로드.

이미지·CSS까지 같이 올리고 싶을 때

파일 여러 개를 한 번에 드래그하면 그대로 올라갑니다. index.html이 같은 경로에 있으면 돼요.

URL 이름을 바꾸고 싶을 때

Worker 화면 → Settings → 프로젝트 이름 변경. URL도 함께 바뀝니다 (기존 URL은 끊어져요).

OPTION B Netlify로 올리기

Netlify에
올리기

드래그드롭 한 번으로 URL이 나오는 가장 쉬운 서비스예요. 단, 네트워크에 따라 접속이 막히는 경우가 있어요.

가입 (1분)

  1. netlify.com → 우측 상단 Sign up
  2. 이메일 + 비밀번호 입력 → 받은 메일에서 확인 링크 클릭

GitHub 계정 있는 분은 "Sign up with GitHub" 선택하면 10초.

배포 — 3단계

  1. 로그인 후 상단 Add new site → Deploy manually
  2. index.html 파일을 창에 드래그드롭
  3. 자동 생성된 URL 확인
    URL 예: graceful-starfish-abc.netlify.app
수정본은 어떻게? 해당 사이트 → Deploys 탭 → 새 index.html 드래그드롭. URL은 그대로, 내용만 바뀝니다.
