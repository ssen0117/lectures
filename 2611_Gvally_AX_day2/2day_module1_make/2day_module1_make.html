1-1 방법 물어보기

STEP 1-1 · 복사해서 자기 걸로 바꾸기 내가 하는 일은 [상품]을 [주요 고객]에 주로 납품하는 일이야. 우리 상품이나 비슷한 상품에 대한 고객 리뷰·블로그 후기를 매일 아침 이메일로 자동으로 받아보고 싶어. 관심 키워드 3개 정도를 한꺼번에 받아볼 수 있는 방법을 알려줘.

STEP 2 메이크 들어가서 시나리오 만들기

자동 발송
세팅하기

Make(make.com)는 노코드 자동화 도구예요. Claude가 알려준 주소를 Make에 꽂으면 매일 내 Gmail로 메일을 보내주는 로봇이 만들어집니다.

가입 (1분)

  2. "Sign up with Google" → Google 계정 1-click
  3. 설문은 아무거나 넘기면 끝

STEP 2 Make 화면에서 직접 하기

Make 화면
한 바퀴

Claude 안내를 실제 화면에 놓아보면 이렇게 됩니다. 동그라미 하나 = 모듈 하나, 왼쪽에서 오른쪽으로 일이 흘러가요.

화면 구성

가운데 넓은 판
캔버스 — 모듈 놓는 곳
모듈(동그라미) 클릭
설정 창 — 주소·받는 사람 입력
입력 칸 클릭하면 옆에 뜨는 창
매핑 패널 — 앞 모듈 결과를 블럭으로 꽂기
화면 왼쪽 아래
Run once · 시계 · ON — 테스트·예약·켜기

① RSS 모듈 — 글 가져오기

  1. 캔버스 가운데 + → 검색창에 RSS
  2. Retrieve RSS feed items 선택
  3. URL 칸에 STEP 1에서 받은 주소 붙여넣기
  4. 가져올 글 개수는 10 정도면 충분 → OK
  5. 모듈 우클릭 → Run this module only → 글이 들어오는지 확인

Watch는 "새 글이 생길 때마다", Retrieve는 "돌릴 때마다 지금 있는 글을 가져오기"예요. 하루 한 번 묶어 받는 오늘 방식엔 Retrieve가 맞아요.

② Gmail 모듈 — 메일 보내기

  1. RSS 모듈 오른쪽 반원 클릭 → Gmail 검색 → Send an email
  2. Connection → Add → 내 Google 계정으로 로그인 → 허용
  3. To: 내 Gmail 주소
  4. Subject: 메일 제목 (예: 오늘의 리뷰 모음)
  5. Content: 칸 클릭 → 매핑 패널에서 Title, URL 블럭을 클릭해서 꽂기

③ 메일 본문은 코드로 써도 돼요

Content 칸은 글자뿐 아니라 HTML 코드도 받아요. 블럭을 하나하나 꽂는 대신, Claude에게 메일 모양을 코드로 받아 붙여넣고 자리만 블럭으로 바꾸면 끝이에요.

PROMPT · 메일 모양을 코드로 Gmail 메일 본문을 제목, 링크, 날짜가 보기 좋게 나오는 HTML 코드로 만들어줘. Make 매핑 블럭 들어갈 자리는 [TITLE 자리], [LINK 자리] 이런 식으로 표시해줘.

Claude가 준 코드를 Content 칸에 복붙 → [TITLE 자리] 같은 부분만 지우고 그 자리에 매핑 블럭을 꽂으면 돼요. 다음 STEP에서 Text aggregator를 넣으면 이 코드는 aggregator 쪽으로 옮겨가요. Claude가 같이 안내해줘요.

STEP 3 Text aggregator 추가

메일 한 통으로
묶기

지금은 글 개수만큼 메일이 쏟아져요. 하루 한 통에 다 묶어서 깔끔하게 받으려면 한 모듈을 더 끼워 넣습니다.

3-1 한 통으로 묶어달라고 요청

STEP 3 · 복사 지금 메일이 아이템 개수만큼 여러 통 와. 한 메일에 다 묶어서 하루에 1통만 받고 싶어. 어떻게 해?

Claude가 Text aggregator라는 모듈을 RSS와 Gmail 사이에 넣으라고 안내해줘요. 따라서 설정하면 돼요.

Text aggregator 사용법

하는 일 — 여러 개를 하나로 합쳐주는 모듈. RSS가 글 10개를 뱉으면 → 한 덩어리로 묶어 메일 1통에 담아요.

위치 — RSS → [Text aggregator] → Gmail

설정 3가지

  1. Source Module → RSS 선택 (필수! 안 하면 안 돌아감)
  2. Row separator → New row
  3. Text → 아래 템플릿 복붙 후, [...] 자리는 오른쪽 매핑 패널에서 RSS 필드 클릭해서 채우기
Text 템플릿 ━━━━━━━━━━ 📌 [Title] 🔗 [URL] [Description]

Gmail 연결 — Gmail 모듈 Content 칸에 Text aggregator 출력을 한 번 클릭해서 넣으면 끝.

안 되면 Claude에게 — "Text aggregator Source Module 어떻게 설정해?" / "결과가 비었어, 원인이 뭐야?" (스크린샷 같이 올리면 더 빠름)

3-2 메일 모양 다듬기

메일을 열었을 때 어떤 글인지 바로 알 수 있게 포맷을 잡습니다.

PROMPT · 메일 모양 Gmail 모듈 Content 칸에 뭘 넣어야 할지 알려줘. 메일 모양은 링크와 제목, 날짜가 나올 수 있게 표시하는 법을 알려줘.

Claude가 Content 칸에 어떤 내용을 넣고, 오른쪽 매핑 패널에서 어떤 블럭을 클릭해서 꽂을지 안내해줘요. 코드로 한 번에 넣는 법은 앞 쪽 ③을 참고하세요.

3-3 테스트 → 메일 확인

Make 좌하단 Run once → 내 Gmail 받은편지함 열기 → 메일 한 통에 글 여러 개가 깔끔하게 들어있으면 완주 성공 🎉

여기까지 왔다면 Claude가 조사해준 주제의 리뷰·후기가 매일 내 메일로 들어올 준비가 끝났어요. 나중에 "매일 아침 8시에 자동으로 돌리고 싶어"라고 Claude에게 한 번 더 물어보면, 스케줄까지 설정해서 진짜 자동화가 완성됩니다.
