## 4. 헤더 로고 크기·정렬 조정

> 슬라이드들마다 들어간 로고 이미지는 지금보다 전체 1.3배 정도 키우고, 아래라인을 슬라이드 제목 아래 라인이랑 맞춰줘

**적용**
- 헤더 로고 높이 `3.7% → 4.8%` (1.3배)
- 로고 하단 라인이 한글 제목의 시각적 베이스라인과 일치하도록 `top: 9.5%`

## 5. 6쪽 그래프 수정 (Y축·데이터 레이블)

> 6p 그래프 세로축 끝값을 100으로 잡고, 데이터 레이블은 막대그래프 내부 끝값쪽으로 맞춰줘. 우리 마스크의 데이터 레이블 색상은 흰색, 두께는 Bold, 지금보다 숫자 크기 3배 정도만 키우자.

**적용 (HTML)**
- Y축 최대값: 110 → **100**
- 데이터 레이블 위치: 막대 외부 상단 → **막대 내부 상단**
- 우리 마스크 라벨: 흰색, Bold, 11px → **33px** (약 3배)

---

## 6. PPT 동기화 + % 기호 크기

> 응. PPT 파일도 같은 방향으로 맞추고, % 기호는 데이터레이블 숫자보다 60%정도 크기로 줄여줘.

**적용**
- 5번과 동일한 변경을 PPT 파일에도 반영
- `%` 기호 크기 = 숫자의 **60%**
  - HTML: 33px → 20px (`%`)
  - PPT: 24pt → 14pt (`%`)
- PowerPoint 네이티브 차트는 단일 라벨 안에서 폰트 크기 혼용이 안 되므로, 차트 위에 숫자·% 텍스트 박스를 수동 오버레이
