STEP 1 프로젝트 만들기

작업 공간부터

클라이언트가 여러 명이면 채팅창 하나로는 섞여요. 프로젝트 하나를 만들고, 클라이언트마다 세션을 쌓아가는 게 깔끔합니다.

프로젝트 생성

Claude 좌측 상단 프로젝트 → 새 프로젝트

  • 이름: "클라이언트 제안서"
  • 목적: "클라이언트별 맞춤형 제안서 작업 공간" 정도 한 줄
지침은 지금 비워두세요 수업 중엔 지침을 안 쓰고 세션에서 바로 시작합니다. 나중에 반복 작업이 많아지면 그때 지침에 공통 규칙을 넣으면 돼요.
STEP 2 샘플 폴더 다운로드

폴더 받기

수업 자료 사이트에서 제안서_샘플.zip을 받아서 바탕화면에 압축을 풉니다.

샘플 안에 있는 것

  • 마스터 PNG 2장 (우리 회사 제안서 템플릿)
  • 가상 클라이언트 로고 2개 (GreenSquare, BlueLab)

자기 자료 가져오셨다면

샘플 폴더 안에 자기 클라이언트 로고나 자기 회사 템플릿 PNG를 추가로 넣어두세요. 수업에서는 섞어서 작업합니다.

GitHub에서 받습니다 수업 자료는 GitHub이라는 공개 저장소에 올려져 있어요. 가입·로그인 없이 "Download ZIP" 한 번으로 받아집니다. 자료를 쌓고 공유하는 사람에게도 좋은 도구예요. (오후 끝에 간단히 짚습니다)
STEP 3 새 세션에 폴더 업로드

폴더 통째로
Claude에게

STEP 1에서 만든 프로젝트에 새 세션을 열고, 바탕화면의 폴더를 통째로 드래그해서 올립니다.

데스크톱 앱이 필요한 이유 폴더를 열어보고 그 안에 새 폴더를 만들고 파일을 이동하는 작업은 Claude 데스크톱 앱에서만 가능해요. 뒷단계에서 Claude가 파일 정리, 클라이언트별 폴더 생성, 결과물 저장까지 하기 때문에 꼭 데스크톱 앱이어야 합니다.

세션 이름

세션 이름을 "제안서 1차" 또는 날짜 정도로 지어두면, 나중에 클라이언트가 늘어나도 찾기 쉬워요.

STEP 4 Claude에게 파일 정리 맡기기

정리부터
Claude에게

폴더를 통째로 올리면 내용이 섞여 보여요. Claude에게 열어보고 정리하라고 시킵니다.

PROMPT 이 폴더에 뭐가 있는지 봐주고, 우리 회사 자료와 클라이언트 자료를 각각 폴더로 나눠서 정리해줘.

Claude가 폴더 안을 열어보고, 로고가 어느 회사 것인지·마스터 PNG가 공용인지 판단해서 구조를 잡아줍니다. 결과가 맘에 들면 다음 단계로, 다르게 묶고 싶으면 말로 요청하세요.

작업이 끝나면 이런 모양이 됩니다

우리 회사
  • 마스터 PNG
  • design.md
  • 제안서 내용.md
클라이언트 1
  • 로고
  • PPT 제안서
  • HTML 제안서
클라이언트 2
  • 로고
  • PPT 제안서
  • HTML 제안서

지금은 로고와 마스터 PNG만 있어요. STEP 5~8을 거치면서 design.md, 제안서 내용, PPT, HTML이 각자 자리에 쌓입니다. 클라이언트가 늘어나면 폴더 하나씩 추가되고요.

STEP 5 마스터 디자인 규칙 추출

이미지를
디자인 규칙으로

우리 회사 마스터 PNG를 그대로 두면 Claude가 보는 느낌만으로 작업해요. 색·간격·레이아웃을 글로 정리해두면 뒷단계에서 품질이 확 올라갑니다.

PROMPT 우리 회사 폴더의 이미지에서 보이는 특징을 디자인 규칙으로 만들어줘. 결과는 그 폴더 안에 design.md 로 저장해줘.

Claude가 이미지에서 색·위치·반복 요소를 분석해서 글로 정리합니다. 이 파일이 뒷단계에서 "우리 회사 디자인 가이드" 역할을 해요.

좀 더 깎아보기

규칙이 "파란색 바", "둥근 박스" 같은 말로만 적혔을 때

PROMPT 눈대중으로 보지 말고 이미지를 코드로 측정해서 색 코드·좌표·크기를 숫자로 적어줘.
STEP 6 제안서 텍스트 기획

내용부터
구조 있게

디자인 전에 무슨 말을 할지부터 정리합니다. 우리 회사 설명 몇 줄이면 Claude가 일반 제안서 흐름으로 기획해줘요.

PROMPT 우리 회사 제안서 텍스트를 기획해줘. - 우리 회사: [한 줄 설명] - 이번 제안: [무엇을 제안하는지 한 줄] - 어필할 부분: [경쟁사와 다른 점] 일반 제안서 구조로 5~6쪽 분량으로 기획해줘.

Claude가 쪽 구성을 잡아주면 보시고, 섹션별로 수정 요청하면서 다듬어갑니다. 추가 프롬프트는 PPT 디자인 후에 더 넣어도 됩니다.

좀 더 깎아보기

섹션이 내 사업과 안 맞을 때

PROMPT [섹션 이름] 섹션은 [내용]으로 바꿔줘. 다른 섹션은 그대로.

너무 길거나 짧을 때

PROMPT 항목은 각 쪽당 3개 이하. 한 줄 넘지 않게.

Claude가 결과만 보여주고 파일로 저장은 안 할 때

PROMPT 방금 기획한 내용을 우리 회사 폴더에 md 파일로 저장해줘.
STEP 7 클라이언트별 디자인

색은 로고에서,
구조는 우리 것으로

클라이언트 로고 색을 가져다 쓰되, 우리 회사 디자인 구조는 그대로 유지합니다.

PROMPT 방금 만든 제안서 텍스트를 클라이언트별로 PPT로 만들어줘. 클라이언트 로고의 대표 색을 쓰고, 우리 회사 마스터 디자인 구조는 그대로 유지해줘.

결과를 보고 다듬기

처음엔 눈으로 보고 자연어로 요청합니다. 그래도 안 되면 수치로.

상황 이렇게
클라이언트 색이 너무 많이 들어감 클라이언트 색은 좀 줄이고, 우리 회사 색을 더 쓰자
글씨가 흐려서 안 읽힘 글씨가 안 읽혀. 더 진하게
색 비중을 정확히 조정하고 싶을 때 클라이언트 색 30%, 우리 회사 색 70% 비율로
좀 더 깎아보기

자연어로 "어울리게" 요청했는데 결과가 반복해서 어긋날 때는 수치로 요청해보세요.

PROMPT · 수치 조정 제목은 클라이언트 색, 강조 텍스트는 클라이언트 색의 70% 명도, 배경·구조선·화살표는 우리 회사 색 유지. 그래프의 핵심 막대 하나만 클라이언트 색으로.
STEP 8 HTML로 공유하기

PPT 다음은
HTML 버전

제안서를 다 만들었으면 이제 누구에게 어떻게 보낼지 생각할 차례예요. 포맷을 상황에 맞게 선택하는 흐름입니다.

어떤 포맷으로 보낼까?

flowchart TD
  A["제안서 완성"]
  B["누구에게 어떻게 보내나?"]
  C["공식 제출 · 결재 · 입찰
→ PDF 파일"]
  D["대면 미팅 · 인쇄본
→ PDF 파일"]
  E["이메일 · 메신저 · 링크 공유"]
  F["바로 열어보게
모바일에서 가볍게
→ HTML 링크"]
  I["회사 내부
수정 가능성
→ PPT 원본"]

  A --> B
  B --> C
  B --> D
  B --> E
  E --> F
  E --> I

  style A fill:#E3EF26,stroke:#0C342C,stroke-width:2px,color:#0C342C
  style B fill:#076653,stroke:#076653,color:#FFFDEE
  style E fill:#076653,stroke:#076653,color:#FFFDEE
  style C fill:#FFFDEE,stroke:#076653,stroke-width:1.5px,color:#0C342C
  style D fill:#FFFDEE,stroke:#076653,stroke-width:1.5px,color:#0C342C
  style F fill:#FFFDEE,stroke:#076653,stroke-width:1.5px,color:#0C342C
  style I fill:#FFFDEE,stroke:#076653,stroke-width:1.5px,color:#0C342C
왜 HTML까지? PDF는 받는 사람의 수고를, HTML은 보내는 사람의 수고를 줄여요. PDF는 다운로드·뷰어 열기 2단계가 필요하지만, HTML은 링크 하나로 바로 열립니다. 둘 다 만들어두면 상황에 맞게 쓸 수 있어요.

HTML 제안서 만들기

PROMPT 방금 만든 PPT를 클라이언트별 HTML 제안서로 바꿔줘. 슬라이드 넘기듯 쪽마다 이동할 수 있게 해주고, 우리 회사 디자인(design.md)은 그대로 유지해줘.

Claude가 각 클라이언트 폴더에 HTML 파일을 만들어줍니다. 브라우저에서 바로 열어볼 수 있고, 링크로 공유 가능해요.

좀 더 깎아보기

특정 요소의 크기나 위치를 조정하고 싶을 때

PROMPT [위치/요소]를 지금보다 [N배] 크게 키우고, 아래 라인을 [기준]과 맞춰줘.

그래프의 숫자 라벨을 강조하고 싶을 때

PROMPT [쪽 번호] 그래프의 데이터 레이블은 흰색, 두께는 Bold, 지금보다 숫자 크기 [N배] 정도 키워줘. % 기호는 숫자보다 [N%] 크기로.

HTML이 폴더에 저장되지 않고 채팅에만 나올 때

PROMPT 방금 만든 HTML을 각 클라이언트 폴더에 파일로 저장해줘.
