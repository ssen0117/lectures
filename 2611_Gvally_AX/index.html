오늘의 5 STEPS

오늘 끝에는 매일 아침 북마크 눌러서 여는 내 신문 하나가 생깁니다.

FLOW

  1. Claude 채팅에 내 관심사 적기
  2. 아티팩트로 뉴스보드 기본형 만들기
  3. 디자인 — 내 취향대로
  4. 부가 툴 연결 — Claude가 못 하는 거 메꾸기
  5. 부가 툴 실습 — Make 직접 돌려보기
오늘의 전제 프로젝트 설정 없이, Claude 채팅창 하나로 끝냅니다. 지침·설정은 수업 뒤에 "매일 쓰려면" 쪽에서 다룹니다.
STEP 1 내 관심사 적기

채팅창에 적기

가볍게 한 문장으로 시작합니다. 내가 매일 뭘 보고 싶은지를 적는 게 전부예요.

STEP 1 · 복사해서 자기 걸로 바꾸기 내 관심사 뉴스를 매일 한 페이지로 모아보고 싶어. 관심사는 [관심사 2~3개]야.

예: "관심사는 알고리즘, 플랫폼 정책, AI 워크플로우야."
회사명이나 산업 분야를 넣어도 좋아요: "우리 회사는 [산업]이고, 관심사는 ..."

이 단계의 포인트 여기선 그냥 결과를 받아보는 게 목표예요. 채팅창에 글이 쭉 나오면 성공. 모양이 마음에 안 들어도 괜찮아요. 다음 단계에서 신문처럼 바꿀 거예요.
STEP 2 아티팩트로 기본형

열 때마다
새로 읽는 신문

채팅 결과를 아티팩트 신문으로 옮깁니다. 여기서 두 가지가 중요해요. 열 때마다 새로, 그리고 RSS 방식으로.

2-1 아티팩트로 전환

PROMPT · 전환 열 때마다 최신 뉴스를 새로 읽어오는 아티팩트로 만들어줘.

이 한 줄이 없으면 Claude가 지금 뉴스를 박아둔 고정 페이지를 만들어버려요. 매일 열어서 다른 뉴스를 보려면 꼭 들어가야 하는 문장이에요.

2-2 RSS 방식으로

PROMPT · 원문만 지금 아티팩트를 RSS 방식으로 바꿔줘. 요약이나 나한테 추천할 필요는 없으니 그 부분은 모두 삭제해 주고, 최신 7일까지의 콘텐츠가 필요해. 가능한 뉴스 기준으로 가지고 와줘.
허용 창이 뜨면 Claude Browser 허용 창이 떠요. Claude Browser만 켜고 "Claude 사용"은 꺼도 됩니다 — 요약을 원하지 않으면 꺼야 매번 사용량이 안 나가요.

2-3 요약 자리 만들기

RSS가 들어오면 그걸 요약해서 쓸 자리도 보드에 만들어요. 열 때마다 새로 뽑히게.

상단에 "오늘의 핵심" 섹션

PROMPT · 오늘의 핵심 보드 상단에 "오늘의 핵심 3가지" 자리를 하나 더 만들어줘. 각 지면에 들어온 기사들을 종합해서, 내 관심사 기준으로 꼭 알아야 할 핵심 3가지를 뽑아 보여줘. - 한 줄 헤드라인 + 한 줄 이유 - 어떤 기사에서 나왔는지 링크로 연결 - 보드 열 때마다 새로 뽑아줘

각 기사마다 한 줄 요약

PROMPT · 기사별 한 줄 각 기사 제목 아래에 한 줄 요약을 붙여줘. "내 관심사 기준으로 왜 내가 봐야 하는지" 한 줄로. 열 때마다 Claude가 새로 뽑아줘.

요약 자리를 만들면 "Claude 사용"도 켜 두세요 — 매번 Claude가 요약하면서 사용량이 들어갑니다.

좀 더 깎아보기

"아티팩트는 외부 사이트를 못 읽어요" 같은 답이 왔을 때

PROMPT · 브라우저 지정 Claude Browser로 RSS를 직접 읽어오게 만들어줘.

다시 열어도 기사가 그대로일 때 (고정 페이지로 만들어진 경우)

PROMPT · 열 때마다 갱신 열 때마다 Claude Browser로 RSS를 새로 읽어오게 해줘.
STEP 3 디자인 · 내 취향대로

내 신문답게

뼈대가 완성되면 보기 좋게 다듬습니다. 여기부터는 정답이 없어요. 매일 열어보고 싶은 모양으로 바꾸세요.

4-1 지면 레이아웃

PROMPT · 카드 레이아웃 각 피드는 그룹별로 4개씩, 카드 형식으로 맞춰줘. 한 줄에 카드들이 놓이게 해주고, 제목이 너무 길면 ...으로 생략해줘.

4-2 상단 티커

PROMPT · 티커 맨 위에 공간을 만들어서 각 섹션별로 가장 최근 뉴스 제목이 옆으로 흘러가는 티커를 만들어줘.

4-3 일주일 기사량

PROMPT · 일주일 기사량 티커 아래에 작은 영역을 추가해줘. - 평일 5일(월~금)의 날짜별 뉴스 수 - 지면별로 색을 다르게 해서 적절한 그래프로 보여줘 - 작게, 신문 톤에 맞춰 깔끔하게

STEP 4 부가 툴 연결 — 개념

Claude만으로
어려운 거

뉴스보드는 열 때마다 Claude가 공개 RSS를 가져오는 방식이에요. 여기서 멈춰도 좋고, 더 멀리 가고 싶다면 다른 도구와 연결하면 돼요.

Claude 혼자 하기 어려운 3가지

  • 스케줄 자동 실행 — Claude는 내가 열어야 작동함
  • 유튜브 최신 영상 안정 수집 — 아티팩트가 유튜브 RSS를 잘 못 긁어옴
  • 개인 메일·메모 반영 — 매번 복붙하기 번거로움

그 자리를 메꾸는 도구 — Make

Make(make.com) — 노코드 자동화. 조리법 짜듯 블록 연결로 "A가 생기면 B 하기" 자동화해요.

  • 무료 플랜 월 1000회 실행 (개인 쓰기 충분)
  • 유튜브·Gmail·Slack·Notion 등 2000+ 앱 연결
  • Claude에게 매뉴얼 물어보면 됨 — 외울 필요 X

가입 (1분)

  1. make.com → 우측 상단 "Get started free"
  2. "Sign up with Google" 선택 → Google 계정 1-click
  3. 간단한 환영 설문 넘기면 끝
오늘 실습 미리보기 가입만 해두시고, 다음 STEP에서 "유튜브 새 영상 → Gmail 알림" 시나리오를 함께 돌려봅니다.
STEP 5 부가 툴 실습 — Make 돌려보기

Make 직접 돌려보기

이번 단계는 개인 Gmail이 들어가요. 아티팩트로 공유할 필요 없이, 본인 머신에서 돌아가는 자동화를 만듭니다.

오늘 만들 것

"유튜브 채널에 새 영상 올라오면 내 Gmail로 알림" — Make가 매일 체크해서, 새 영상이 있으면 자동으로 내 메일함에 꽂아줍니다.

시작 — Claude에게 전체 흐름 물어보기

PROMPT · 시작 Make 처음 써봐. 유튜브 채널에 새 영상 올라오면 내 Gmail로 알림 받는 시나리오를 만들고 싶어. 가입부터 테스트까지 하나하나 알려줘.

채널 RSS 뽑기

작업 공간부터

클라이언트가 여러 명이면 채팅창 하나로는 섞여요. 프로젝트 하나를 만들고, 클라이언트마다 세션을 쌓아가는 게 깔끔합니다.

데스크톱 앱이 필요한 이유 폴더를 열어보고 그 안에 새 폴더를 만들고 파일을 이동하는 작업은 Claude 데스크톱 앱에서만 가능해요. 뒷단계에서 Claude가 파일 정리, 클라이언트별 폴더 생성, 결과물 저장까지 하기 때문에 꼭 데스크톱 앱이어야 합니다.

왜 HTML까지? PDF는 받는 사람의 수고를, HTML은 보내는 사람의 수고를 줄여요. PDF는 다운로드·뷰어 열기 2단계가 필요하지만, HTML은 링크 하나로 바로 열립니다. 둘 다 만들어두면 상황에 맞게 쓸 수 있어요.

Claude가 각 클라이언트 폴더에 HTML 파일을 만들어줍니다. 브라우저에서 바로 열어볼 수 있고, 링크로 공유 가능해요.

STEP 9 제안서 배포하기

링크로 보낼 수 있게

HTML 제안서를 공유 가능한 URL로 띄우는 단계예요. Netlify를 쓰면 Claude가 수정본을 만들어줄 때마다 가볍게 재배포할 수 있어요.

Netlify 가입 (1분)

  1. netlify.com 접속 → 우측 상단 Sign up
  2. "Sign up with email" 선택 → Gmail 등 이메일 + 비밀번호 입력
  3. 받은 메일에서 확인 링크 클릭 → 가입 완료

※ Google 1-click 로그인은 지원 안 해요. GitHub 계정 있는 분은 "Sign up with GitHub" 선택하면 10초.

배포 — 드래그드롭 4단계

  1. 로그인 후 상단 "Add new site" → "Deploy manually"
  2. HTML 파일을 창에 드래그드롭
  3. 자동 생성된 URL 확인 (예: graceful-starfish-abc.netlify.app)
  4. Site configuration → Change site name → 알아보기 쉬운 이름으로 변경
    예: greensquare-proposal.netlify.app
수정본은 어떻게 반영? 해당 사이트 → Deploys 탭 → 새 HTML 파일 드래그드롭. URL은 그대로, 내용만 바뀝니다. Claude가 V2 만들어주면 → Deploys에 드롭 → 끝. commit·push 단계가 없어서 반복이 가볍습니다.

선택 옵션

견적·조건 등 민감한 내용이 있을 때
PDF로 보내기
꼭 HTML인데 비공개가 필요할 때
StaticCrypt

StaticCrypt (robinmoisson.github.io/staticrypt) — HTML 파일 올리고 비번 설정하면 비번 걸린 HTML로 변환돼요. 그걸 Netlify에 올리고 URL과 비번을 따로 전달하면 됩니다. 완전 무료, 외부 서버에 자료 안 남음 (브라우저에서 암호화).

관리 팁

  • 안 쓰는 사이트는 Site configuration → Delete site 로 정리
  • URL이 길면 bit.ly 같은 단축 URL 서비스로 깔끔하게
  • Netlify Drop(app.netlify.com/drop)이라는 로그인 없는 입구도 있어요 — 24시간 뒤 사라지니 "급하게 한 번 보여줄 때" 용
STEP 10 클라이언트 맞춤별 앱 만들기

제안서 다음은
미니 앱으로

제안서까지 만들었으면 그 자료로 작은 업무 앱도 바로 띄울 수 있어요. 클라이언트마다 다르게 적용되는 요소가 있으면 "우리 팀 전용" 느낌이 확 올라와요.

1 · 앱 아이디어 받기

PROMPT · 추천 우리 업무에 도움될만한 미니 앱을 추천해줘. 클라이언트별로 맞춤이 되는 요소가 있으면 좋겠어.

2 · 어떤 앱으로 만들지 정하기

PROMPT · 구체화 클라이언트별 맞춤 [견적서] 앱으로 가자. 데이터는 모두 더미값으로 채우고, PDF로 다운로드 받을 수 있게 해줘.

[견적서] 자리에 리포트 요약, 미팅 노트, 체크리스트 등 자기 업무 양식 넣어도 돼요.

3 · 폴더에 있는 클라이언트 자동 반영

PROMPT · 폴더 읽기 폴더에 추가된 클라이언트별로 선택할 수 있게 메뉴를 만들어줘. 각 클라이언트 로고를 앱 상단에 표시해 주고.
